## LEVANTAMENTO DE REQUISITOS

## REQUISITOS FUNCIONAIS
Requisitos funcionais definem o que o sistema deve fazer, enquanto requisitos não funcionais definem como o sistema deve operar e os critérios de qualidade que deve atender.

# Exemplos Práticos de Requisitos Funcionais
Login de usuário: O sistema deve permitir que os usuários acessem suas contas com autenticação segura. 

Registro de novo usuário: Deve ser possível criar uma conta fornecendo informações pessoais, como nome, endereço e data de nascimento. 

Recuperação de senha: O sistema deve permitir que o usuário recupere a senha via e-mail ou perguntas de segurança.

## REQUISITOS NÃO FUNCIONAIS
Requisitos não funcionais (RNFs) definem como um sistema deve operar, estabelecendo padrões de qualidade, desempenho, segurança e usabilidade, em vez de descrever funcionalidades específicas.

# Exemplos Comuns de Requisitos Não Funcionais
Desempenho: Tempo de resposta do sistema, capacidade de processamento e latência. Por exemplo, "O sistema deve processar solicitações de usuários em até 2 segundos, mesmo sob alto tráfego". 

Disponibilidade e Confiabilidade: Garantia de operação contínua e tolerância a falhas. Exemplo: "O sistema deve manter 99,9% de disponibilidade e recuperar-se automaticamente de falhas críticas". 

Segurança: Proteção de dados e controle de acesso. Exemplo: "Todos os dados sensíveis devem ser criptografados e o acesso restrito a usuários autenticados". 

Usabilidade: Facilidade de uso e experiência do usuário. Exemplo: "A interface deve ser intuitiva, permitindo que novos usuários completem tarefas básicas sem treinamento prévio". 

## REGRAS DE NEGÓCIOS
Regras de negócio são diretrizes que definem, restringem e orientam as decisões e operações de uma empresa, garantindo consistência, padronização e alinhamento com os objetivos organizacionais.

# Exemplos práticos de regras de negócio
Aprovação de despesas: Todas as despesas acima de R$ 5.000 devem ser aprovadas pelo gerente financeiro. 

Concessão de crédito: Clientes só têm crédito aprovado se não possuírem pagamentos em atraso e tiverem score acima de 700. 

Limites de transação: O limite diário de transações em um sistema bancário online é de R$ 50.000.
